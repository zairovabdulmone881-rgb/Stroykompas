# Строй Компас — обновлённый статический сайт

## Что внутри
- `index.html` — главная
- `services/` — список услуг и отдельные страницы
- `projects/` — примеры направлений работ (визуальные макеты, не реальные объекты)
- `calculator/` — калькулятор базовой ориентировочной стоимости
- `contacts/` — контакты
- `assets/css/style.css` — единый адаптивный дизайн
- `assets/js/main.js` — мобильное меню и калькулятор

## Публикация на GitHub Pages
1. Распакуйте архив.
2. Загрузите содержимое папки в корень репозитория `Stroykompas`, сохраняя структуру папок.
3. Замените существующие файлы с теми же именами.
4. Нажмите Commit changes.
5. GitHub Pages должен публиковать ветку `main` из корня репозитория.

Ссылки рассчитаны на адрес `https://zairovabdulmone881-rgb.github.io/Stroykompas/`.

## Примечания
- Цены указаны как ориентировочные стартовые цены, сохранены из прежнего содержания сайта.
- Проектные изображения на странице «Проекты» — CSS-макеты, а не фотографии выполненных заказов.
- Форма расчёта передаёт сообщение в WhatsApp; отдельного серверного backend у статического сайта нет.
- Для подключения Telegram укажите действительную ссылку на аккаунт/канал.
