# Строй Компас — первая версия

Статический многостраничный сайт HTML/CSS/JS для GitHub Pages.

## Включено
- Главная страница и отдельные страницы проектов, услуг, калькулятора, советов, контактов.
- RU/EN/FR переключатель для текстов, помеченных атрибутами перевода (пока в основном на главной).
- Цены сохранены с текущего сайта: покраска 380 ₽/м², плитка 800 ₽/м², электрика 450 ₽/точка, сантехника 2 000 ₽/точка.
- Адаптивный дизайн, меню телефона, калькулятор, 404, robots.txt, sitemap.xml.

## Структура
- `index.html` — главная
- `projects/index.html` — проекты
- `services/index.html` и отдельные HTML-файлы услуг
- `calculator/index.html` — калькулятор
- `blog/index.html` — советы
- `contacts/index.html` — форма заявки
- `assets/css/style.css`, `assets/js/` — стили и логика

## Публикация
1. Скачайте архив и распакуйте.
2. Сделайте резервную копию репозитория.
3. Загрузите содержимое папки в корень репозитория `Stroykompas`, сохранив папки.
4. В Settings → Pages проверьте публикацию из `main` и корня `/`.
5. Проверьте все страницы на телефоне и компьютере.

## Перед публикацией
- Цены перенесены с текущего сайта, но их актуальность нужно подтвердить.
- Изображения — иллюстративные; не выдавайте их за реальные завершённые проекты.
- WhatsApp использует номер `+7 996 688-99-79`. Telegram-ссылка пока общая — замените на точный аккаунт/бот.
- Форма заявок пока открывает WhatsApp с подготовленным текстом, но не хранит обращения в базе.
- Переводы внутренних страниц нужно расширить для полного многоязычного сайта.
- Для админ-панели, базы заявок и настоящего AI-консультанта потребуется backend или внешний сервис.
